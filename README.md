# AcadTime-Automatic-Timetable-Generator
AcadTime is an intelligent **automatic timetable generation system** designed to simplify the complex and time-consuming process of creating academic schedules.  
It automatically assigns **teachers, subjects, classrooms, and batches** into available time slots while ensuring that **no conflicts occur**.

This project is useful for **schools, colleges, and universities** that want to replace manual timetable creation with a fast, optimized, and error-free solution.

---

## 🚀 Features

- Automatic timetable generation with **zero clashes**
- Conflict handling for:
  - Teachers  
  - Rooms  
  - Student batches  
- Smart **slot allocation algorithm**
- Easy **manual data input** for teachers, courses, rooms, and batches
- Structured and readable **final timetable output**
- Scalable design for real academic environments

---

---

## 📂 Project Workflow

1. Enter basic academic data  
   - Teachers  
   - Subjects  
   - Rooms  
   - Batches  

2. System builds **occupancy matrices**  
   - Teacher availability  
   - Room availability  
   - Batch schedule  

3. Algorithm assigns slots **without conflicts**

4. Final **optimized timetable** is generated automatically.
